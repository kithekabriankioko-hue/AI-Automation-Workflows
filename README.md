# AI Automation Workflows

A collection of hands-on Make.com automation projects I built to practice AI-assisted workflow automation, API integration, validation, and business logic.

I am building practical automation skills alongside my cybersecurity/SOC background, with a focus on understanding how AI can be used within controlled and reliable workflows.

## Projects

### 01 — AI Employee Access Request Automation
Automates employee access requests using AI classification, validation, routing, human review, API execution, and logging.

### 02 — AI Operations Request & Approval Automation
Uses AI to classify operational requests and applies validation, approval logic, API actions, and logging.

### 03 — AI Customer Support Request Automation
Processes customer support requests with AI classification, structured JSON, validation, routing, and ticket-related actions.

### 04 — AI Incident Triage & Escalation
Uses AI to help classify incidents and route them based on priority and predefined workflow rules.

### 05 — Management Access Review & Approval
Automates access-review workflows with AI-assisted analysis, validation, approval decisions, and record keeping.

## About This Repository

These are **hands-on learning and portfolio projects**, not production systems. They demonstrate how I approach automation problems, structure workflows, validate AI output, and connect different services.

Each project contains its own README, sanitized Make.com blueprint, sample data, and workflow screenshots.
